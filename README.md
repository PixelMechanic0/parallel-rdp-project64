# paraLLEl RDP Plugin for Project64

A port of **paraLLEl RDP** for **Project64**

## About

This project brings paraLLEl RDP to Project64 as a graphics plugin.

Its main feature is native Vulkan presentation, allowing the plugin to present rendered output directly through Vulkan.

## Features

* paraLLEl RDP support for Project64
* Native Vulkan presentation

## Build

On Windows, build the plugin with:

```sh
make all
```
